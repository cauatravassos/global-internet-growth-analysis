# Global Internet Growth Analysis 🌐

## About the Project

This project explores the historical growth of Internet users worldwide, analyzing data from 1990 to 2024.

The objective is to understand how Internet access has expanded over time and examine global population and regional trends.

## Technologies Used

- Python
- Pandas
- Data Analysis
- Jupyter Notebook

## Dataset

The project uses historical datasets related to:

- Global Internet users
- Historical world population
- Internet users by continent
- Population by continent

## Analysis

The analysis explores historical trends, data filtering, comparisons, and the expansion of Internet access worldwide.

## Project Structure

- `world-connected-project.ipynb` – Main analysis notebook.
- `.csv` files – Datasets used in the analysis.
